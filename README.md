# 藏医药藏汉双语知识资源：600条三元组样例

本资源是论文《面向藏医药知识计算的藏汉双语知识资源构建与质量评价》的三元组样例，内容来自《四部医典》和曼唐的规范化实体关系数据，用于查看藏汉字段、实体类型、关系表达及知识模式。

**本次仅提供600条样例及本说明文件，未包含完整资源、独立实体登记表、检查脚本或链接预测实验划分。论文中的全量统计、1,000条人工评价与8,000条链接预测实验均不以这600条样例为统计或实验对象。**

## 抽样方法

1. 按“数据来源＋关系_汉”分层，并按Python字符串元组的默认顺序排列30个统计层；各层候选记录保持原工作表顺序。
2. 每层先分配5条；该层不足5条时全部纳入。
3. 剩余名额按各层尚未抽取的记录数量比例分配：先取整数部分，再按余数从大到小补足至600条；余数相同时按上述层顺序分配。
4. 使用Python标准库`random.Random(20261025)`，依次在各层通过`sample`进行无放回抽取。
5. 将选中记录恢复为原工作表顺序，保留原始`triple_id`、来源和行号。

该方案优先保证关系与来源覆盖，属于非等比例分层抽样。因此，样例中的关系频率、来源占比及问题比例不能直接作为完整资源的总体估计。本样例也不同于论文中的人工评价样本。

## 字段说明

所有字段名和字段值均从原表保留。JSON顶层为数组，每个元素为一个三元组对象。中文与藏文直接以UTF-8字符保存，不转换为Unicode转义序列。原表空白单元格转换为JSON的`null`，原有文本和整数保持相应数据类型；未用零、虚构名称或人工结论填补缺失内容。

| 字段 | 含义 |
| --- | --- |
| `triple_id` | 原有三元组编号，保留原值；样例未重新连续编号。 |
| `数据来源` | 记录所属来源：《四部医典》或曼唐。 |
| `原始行号` | 原始关系表的Excel行号，不是JSON数组中的索引。 |
| `头实体_汉` | 头实体的汉文名称。 |
| `头实体_藏` | 头实体的藏文名称。 |
| `头实体类型_汉` | 头实体的规范中文类型。 |
| `头实体类型_藏` | 头实体类型的藏文表达。 |
| `关系_汉` | 关系的中文标签。 |
| `关系_藏` | 关系的藏文表达。 |
| `尾实体_汉` | 尾实体的汉文名称。 |
| `尾实体_藏` | 尾实体的藏文名称。 |
| `尾实体类型_汉` | 尾实体的规范中文类型。 |
| `尾实体类型_藏` | 尾实体类型的藏文表达。 |
| `H-R-T Schema` | 头实体中文类型—中文关系—尾实体中文类型。 |
| `变更字段` | 原表保留的前一轮规范化变更字段记录。 |
| `本次修订字段` | 原表保留的本轮修订字段记录；不表示本次抽样修改了内容。 |
| `双语关键字段完整` | 头实体、关系、尾实体的藏汉名称共6个字段均非空时为1，否则为0；仅反映字段完整性。 |
| `头实体登记` | 头实体按汉文名称与规范类型在两来源联合实体登记表中的匹配结果。 |
| `尾实体登记` | 尾实体按汉文名称与规范类型在两来源联合实体登记表中的匹配结果。 |
| `待核验事项` | 原表标记的待核验问题；空白不等同于人工确认全部正确。 |
| `术语多表记候选` | 同一汉文名称及类型出现多种藏文表记的候选标记，不直接判为错误。 |
| `处理状态` | 原表记录的规则检查及修订状态，不代表人工评价标签。 |
| `人工复核结论` | 原表预留的人工复核结论字段；未填写的保留空白。 |

`triple_id`用于定位记录，不作为跨源医学概念ID。按名称建立图节点时应保留类型与来源信息，避免直接合并同名但语义角色不同的记录。

## 读取与使用

JSON文件可在GitHub或支持UTF-8的文本编辑器中查看，也可直接通过Python标准库读取，无需安装额外依赖。空值`null`读取后对应Python的`None`。藏文显示需要编辑器使用支持藏文的字体，例如Microsoft Himalaya或Noto Sans Tibetan。

Python读取示例：

```python
import json

with open("藏医药_三元组样例600条.json", encoding="utf-8") as f:
    records = json.load(f)

assert len(records) == 600
triples = [
    (r["头实体_汉"], r["关系_汉"], r["尾实体_汉"])
    for r in records
]
print(triples[:3])

# 按来源筛选
mantang_records = [r for r in records if r["数据来源"] == "曼唐"]
print(len(mantang_records))  # 111
```
