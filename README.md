## 读取与使用

JSON文件可在GitHub或支持UTF-8的文本编辑器中查看，也可直接通过Python标准库读取，无需安装额外依赖。空值`null`读取后对应Python的`None`。藏文显示需要编辑器使用支持藏文的字体，例如Microsoft Himalaya或Noto Sans Tibetan。

Python读取示例：

```python
import json

with open("藏医药_三元组样例600条.json", encoding="utf-8") as f:
    records = json.load(f)

assert len(records) == 600
triples = [
    (r["头实体_汉"], r["关系_汉"], r["尾实体_汉"])
    for r in records
]
print(triples[:3])

# 按来源筛选
mantang_records = [r for r in records if r["数据来源"] == "曼唐"]
print(len(mantang_records))  # 111
```
